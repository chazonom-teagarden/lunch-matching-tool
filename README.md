# ランチマッチングツール

社員を拠点ごとに3人組に分けて、シャッフルランチのグループをつくるツールです。

## 使い方
1. Googleスプレッドシートのデータを全選択してコピー
2. ツールの入力欄にペースト
3. 「グループ作成」をクリック
4. 「アナウンス文をコピー」でSlack等に貼り付け（「シャッフルし直す」で組み直し可）

## グループ分けのルール
- 拠点は **東京 / 大阪 / その他**（東京・大阪以外はすべて「その他」）ごとに分けてグループを作る
- **3人全員が同じチームの組み合わせは作らない**（2人同じ＋1人別、全員別チームはOK）
- 職種の被りは考慮しない
- 3で割り切れない場合：余り1 → 4人組×1、余り2 → 4人組×2（5人の拠点は5人組×1、2人以下の拠点はグループを作らず警告）

## データについて
入力データはブラウザ内のみで処理され、外部サーバには送信されません。
