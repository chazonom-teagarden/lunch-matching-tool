# ランチマッチングツール

社員を拠点ごとに3人組に分けて、シャッフルランチのグループをつくるツールです。

## 使い方（毎月）
1. Googleスプレッドシートの社員データを全選択してコピーし、入力欄にペースト
2. 履歴シートを全選択してコピーし、「過去のマッチング履歴」欄にペースト（初回は空欄でOK）
3. 「今回の実施月」を確認して「グループ作成」をクリック
4. 「アナウンス文をコピー」でSlack等に貼り付け（「シャッフルし直す」で組み直し可）
5. 「TSVコピー」で結果をコピーし、履歴シートの末尾に追記（2回目以降は1行目のヘッダー行は不要。残っていても無視されます）

## グループ分けのルール
- 拠点は **東京 / 大阪 / その他**（東京・大阪以外はすべて「その他」）ごとに分けてグループを作る
- **3人全員が同じチームの組み合わせは作らない**（2人同じ＋1人別、全員別チームはOK）
- **過去に同じグループだった3人は再びそろえない**（4人組・5人組の中に含まれる場合もNG。期間無制限）
- **直近の指定期間（初期値3か月）に同じグループだった2人は、なるべく同じグループにしない**
- 職種の被りは考慮しない
- 3で割り切れない場合：余り1 → 4人組×1、余り2 → 4人組×2（5人の拠点は5人組×1、2人以下の拠点はグループを作らず警告）
- 人数の都合で避けきれない場合は、赤枠（全員同じチーム／過去と同じ3人）・黄枠（直近で同席した2人）で表示

## 履歴シートの形式
| 実施月 | グループ | 拠点 | user_id | 氏名 | チーム | 職種 | 登録拠点 |
|---|---|---|---|---|---|---|---|

- 必須列は `実施月` `グループ` `user_id`（`user_id` がない場合は `氏名` で照合）
- `実施月` は `2026-10` / `2026/10/1` / `2026年10月` のいずれでも可
- 今回の実施月以降の履歴は無視されます（同じ月に組み直すときの二重カウント防止）

## データについて
入力データはブラウザ内のみで処理され、外部サーバには送信されません。
